# Golden Hearts Support Hub

## About the Project
Golden Hearts Support Hub is an Old Age Home Management and Registration System designed to simplify old age home exploration and elderly member registration and management.

## Features
- View available old age homes
- Register elderly members
- View registered members
- Update registration details
- Delete registration records
- Manage registration status

## Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- REST APIs

### Database
- MySQL

## Project Structure
- `frontend/` – React application
- `backend/` – Spring Boot application

## Purpose
The main purpose of this project is to make old age home registration and member management easier, faster, and more organized.
